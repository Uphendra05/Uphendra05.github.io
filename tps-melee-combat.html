Third Person Melee Combat

Unity C# Combat Systems ScriptableObjects Editor Tooling Work in Progress

Overview

This is a Work In Progress modular third-person melee combat framework built around a single animator state. Combos, weapon switching, hit detection and animation events are all driven by code, with no transition webs and no animator parameters.

Combo and weapon system

Combos are a list of ScriptableObject weapon entries, with a lunge toward the closest enemy and an automatic reset after idle time.

Custom animation event tool

Inspired by Unreal Engine's Notify system, events live in a ScriptableObject, separate from the clip, and are edited on a visual timeline inside the Unity inspector.

What you can do:

  • Add a Notify — fires once at a single point in your animation timeline
  • Add a Notify State — active across a duration with begin, tick, and end callbacks
  • ScriptableObject based — event logic and timing live separately from the animation clip
  • Assign unique logic to each event
  • Color code, Place and Name each event for clarity in the timeline
